The Skills Library

Skills teach nebulaONE how to do a particular job well, such as writing minutes or checking a message for clarity. Every skill here has been reviewed and tested. Find one you need, see what it does, and add it to your own nebulaONE in a minute.

How to use a skill

  1. 1

    Find a skill

    Search or browse below, then open More about this skill to check it fits.

  2. 2

    Download or copy it

    Save the skill as a text file, or copy the text straight to your clipboard.

  3. 3

    Add it to nebulaONE

    Go to Settings, My Skills, New Skill. Copy the name and description into their boxes, paste the rest into the instructions, and leave Always On ticked so it switches itself on when needed.

  4. 4

    Just ask

    Start a new chat and ask in your own words. nebulaONE picks the skill when it fits.

Personal skills are only visible to you. If you'd like a skill shared with your team or added for everyone, contact the library's owner.
