Skills Library

Skills teach nebulaONE how to do a particular job well, such as writing minutes or checking a message for clarity. Each skill here has been reviewed and tested. Find one you need, read what it does, and download it to add to your own nebulaONE.

How to use a skill

  1. Find a skill below and open More about this skill to check it fits what you need.
  2. Select Download to save the skill as a text file, or Copy text to copy it.
  3. In nebulaONE, create a new personal skill and add the file or paste in the text.
  4. Start a new chat and ask for the task in your own words. nebulaONE picks the skill when it fits, so you don't need to name it.

Personal skills are only visible to you. If you'd like a skill shared with your team or added for everyone, contact the library's owner.
